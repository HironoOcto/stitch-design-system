# Seline — 合成层（Composition Layer）

> DESIGN.md 的合成层补充。值层见 `adapter.css` / `rules.md`（同预置）；本文件记那些**单个 token 换不动、需图层 / 缩放 / 滤镜才成立**的长相——分层产品拼贴、图像材质、升起影、内联强调、刻意拒绝。**seline 的合成层本就克制**：DESIGN.md 已忠实覆盖大部分，本文件只补它没记的那一层（分层拼贴）+ 把「怎么复刻」讲透。合成层与 DESIGN.md 冲突时以本文件为准。

## 一句话 ← DESIGN.md 概览 + 真站观感

seline 是**暖纸上的克制编辑排版**：整页平铺暖石纸底，无暗幕、无色晕。高级感不来自氛围铺底，而来自**产品 UI 的分层处理**——功能卡里塞的不是一张扁平截图，而是几片缩到 ~0.8–0.9、微微斜置、柔叠的真实仪表盘碎片，读起来像「活的」界面；截图统一去彩压成单色、只留一个青；hero 主截图与内联产品预览各吃一道深软影浮起。纸是舞台，青是唯一的声音。

## 1. 分层产品拼贴 layered UI ← 补 DESIGN.md（其只记「产品截图作 hero」，未记分层缩放拼贴）

- 功能卡内的产品界面**不是一张完整平截图**：取几片界面碎片（图表 / 面板 / 列表），各自**缩到约 0.8–0.9 尺寸**、**轻微斜置（约 1–3°）**、**柔性重叠错位**摆放，造出「界面在动、有纵深」的拼贴感，而非静态贴图。
- 拼贴是**克制**的——错位幅度小、旋转轻，服务「编辑感」而非杂乱；一张卡里两三片足矣，别铺满。
- mascot 贴纸同理带**轻微旋转**（比界面碎片略大一点），像随手贴上去的一枚 sticker，不是正襟危坐的图标。

## 2. 图像材质与升起影 image & elevation ← DESIGN.md Imagery / Shadows（提为复刻配方）

- 所有产品截图**去彩压成单色**（灰度 + 轻微降对比），让仪表盘里的数据色不与那一个青抢声音——**这是「高级感」的直接来源，别省**：留原彩就变成花哨 SaaS，破编辑克制。
- mascot 是**灰度线描**（outline-only），配一道**柔性 drop-shadow** 给贴纸式浅纵深；每区块只出现一次，作单色数据 UI 的俏皮配重。
- **升起影专属产品预览**：hero 主截图与内联产品预览各吃一道**深软环境影**（大扩散、低透明），像浮在纸上；内容卡一律靠 1px 发丝线撑结构，**不加重影**。深影是产品图的特权，不外借。

## 3. 内联强调设备 highlight ← DESIGN.md Signature Highlight（提为合成层设备）

- 每条标题**恰好一处** highlight：关键词用青字坐在一枚淡蓝药丸底上（药丸随字宽包裹、小圆角），是全条标题**唯一**的彩色。它总落在 value-prop 词上，绝不进正文、绝不进导航。
- **中文注意**：药丸包裹拉丁短语自然；中文关键词改用**同款淡蓝药丸底 + 青字**包住 2–4 字词，勿逐字包，保持「一处强调」的克制。

## 4. 刻意拒绝 refuses（复刻时主动不做）← DESIGN.md Don'ts + 真站实测

> 站的身份也由它**拒绝什么**定义。这些是「刻意无」，复刻时必须**主动不做**。

- **刻意无暗幕**：整页浅色纸底到底，无近黑 / 深色满幅区块；只有仪表盘内的小 tab 药丸用深色点缀，那是组件不是舞台。别学别的站插暗区。
- **刻意无装饰色晕 / 玻璃拟态**：设计刻意扁平、纸质感。**更正**：DESIGN.md 说「不做渐变」应理解为「不做装饰性**彩色**渐变 / 色晕」——真站在区块边缘用一道**近乎无形的白 → 微灰白渐隐**收干净边缘，那是无彩的柔化、不是色晕；除此之外全平涂。
- **产品截图不还彩**：永远保持单色处理，只加软影与轻斜叠；还原满彩即破克制（区别于把数据色当卖点的花哨站）。
- **标题不加粗**：强调靠字号 + 那一处青色 highlight，不靠 weight（衬线/几何无衬线都恒 400）。
