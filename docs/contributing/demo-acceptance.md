# Demo 平台验收清单（每个迁移 / 新增组件都走一遍）

> 给**验收 agent**（也给人）对照用的硬清单：一个组件做完，照此逐条核，全过才可关闭。
> 基准是 `design-rules.md`（全局）+ 该站 `rules.md`（每站）**本身**——本清单只指过去、不复述规则。
> 验收站：**seline 逐条** + **steep 冒烟**（steep 暂无 `rules.md`；将来要逐条先按 [onboard-site.md](./onboard-site.md) 生成，不手写）。

## 第一段 · `npm run ci` 全绿（先决闸）

验收 agent 先复跑 `npm run ci`（pre-commit 已强制，这里再确认一遍）。它覆盖 `design-rules.md` 硬规则 1–5，**不必再肉眼核**：

- 无硬编码主题值（颜色 / 圆角 / 字体全走 `var(--stitch-*)`）
- 无某站原始变量（`--color-*` 等）
- 图标全 `<Icon>`；无 emoji / 裸 `<svg>` / Unicode 符号
- 动效走 `--stitch-motion-*`，时长 0.15–0.35s
- 关键文字对比 ≥ AA（`test:a11y`）
- 组件测试 7 维度通过、`build` 成功、`check:docs` 通过（skill 参考已由 `build:refs` 生成 `## <Name>` 条目）

**ci 不绿 = 直接不通过，无需往下走。**

## 第二段 · 在 demo 上逐条核（ci 覆盖不到的）

准备：`npm run demo` 起 demo，浏览器打开该组件页 `#/<name>`。

| # | 查什么 | 方法 | 通过标准 |
|---|---|---|---|
| 1 | **上架正确** | 看侧栏 + 打开 console | 组件在**正确的族**下出现；点进去页面**不空白**；console **无 warn / error**（尤其无"文件夹名不在族表"的 warn） |
| 2 | **示例够全** | 看该组件 demo 页 | 展示了该组件适用的：**全部 size**、**全部语义态**（default / danger / success / warning / info 中该组件适用的）、**disabled**、**受控与非受控关键路径**、**核心交互**（展开 / 选中 / 开浮层…）。只有默认态 = **不通过** |
| 3 | **换肤生效** | 顶栏在 **seline ↔ steep** 切，逐属性对比 | 颜色 / 圆角 / 字体 / 阴影**随切换变化**；两站均不破版、不溢出、不丢对比。**任一视觉属性切换后纹丝不动 → 判有硬编码漏网 → 不通过**（这是 ci 硬规则 1 的人眼冗余兜底）。**例外：纯布局 / 无皮件（如 `AspectRatio`——只有比例 / 结构，无颜色 / 圆角 / 字体 / 阴影可上）本条 N/A，冒烟不破版即可** |
| 4 | **键盘可达** | 只用键盘操作一遍 | Tab 可达且**焦点环可见**（focus-visible）；Enter / Space 触发；有浮层的 Esc 可关；列表 / 菜单方向键可走。按组件类型该有的任一缺失 = **不通过** |
| 5 | **seline 长相逐条** | 打开 `sites/seline/rules.md`，定位**该组件规格段** + 该站 **Do / Don't**；在 seline 下逐行核。**该组件若在 `rules.md` 无规格段（radix 净新增件常态）：跳过规格段逐条，改核通用角色一致性 + Do/Don't + `design-rules.md` 人眼项** | 该组件在 `rules.md` 的**每一条**规格（圆角档 / 边框 / 阴影策略 / 字号字重 / padding / focus ring 等）在 demo 上都成立；该站 **Do / Don't 每一条**都不违反；`design-rules.md` 的人眼项也成立——**60-30-10 配色比例**、**动效手感自然**、**焦点环存在**。**逐条勾；任一条不符 = 不通过，并记录是哪一条**。**radix 净新增件 `rules.md` 无专属规格段时：规格逐条退化为「与同族既有件的圆角 / 边框 / 阴影档一致」+ Do/Don't + design-rules 人眼项都成立；无规格可依处的长相取舍记 `预建笔记.md` 交人拍板（同 Toggle 先例）** |
| 6 | **steep 冒烟** | 切到 steep 看一眼 | 组件在 steep 下正常渲染、换肤生效、不破版（steep 暂无 `rules.md`，**不做逐条**）。破版 = **不通过** |
| 7 | **迁移/预建笔记清账** | 迁移件查仓库根 `迁移笔记.md`；radix 预建件查根 `预建笔记.md`（均为构建期临时文件，手写件可无） | 该组件在对应笔记里的适配决策 / 待确认项：已由人**定夺**——迁移件（未映射值已回填映射表）、radix 预建件（data-\* 已照 `<slug>.md` 核准 + API/边界适配已确认）；无遗留 open 项挂在该组件名下 |

## 结论

- **全部通过** → 该组件 issue 可关。
- **任一不通过** → 退回，注明是哪一条（第 5 条要具体到 `rules.md` 的哪一行规格）。
