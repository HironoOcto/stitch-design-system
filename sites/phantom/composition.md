# Phantom — 合成层（Composition Layer）

> DESIGN.md 的合成层补充。值层见 `adapter.css` / `rules.md`（同预置）；本文件记那些**单个 token 换不动、需图层 / 满出血 / 明暗编排才成立**的长相——明暗摆荡、糖果卡节奏、插画贴纸拼贴、辉光、ghost 字形设备、刻意拒绝。**DESIGN.md 把 phantom 建模成了「纯排版、无图形、扁平纯色」——与真站相反**：真实 phantom 是一座**插画糖果卡世界**，被一幕深色动态 hero 领起。纯排版只是骨架，不是全部。合成层与 DESIGN.md 的austere印象冲突时以本文件为准。

## 一句话 ← DESIGN.md 概览 + 真站观感

phantom 是**在近白 canvas 上摆荡的糖果卡剧场**：一幕**满出血深色动态 hero**（暖调运动纹理 + 白色巨标）领起明暗节奏；往下每一行功能块都是几张**大圆角饱和色卡片**——淡紫 / 矢车菊蓝 / 奶黄 / 腮红 / 灰，每行夹**一张近黑或深紫暗卡**打出明暗摆荡；卡里满是 **ghost 吉祥物、贴纸式图形、彩色色块与真实产品截图**。主 CTA 是「浅上加浅」的淡紫按钮，只靠一道**淡紫辉光**显形。ghost 替换标题元音是招牌字形设备。

## 1. 明暗摆荡 dark act ← 更正 DESIGN.md「pure typography」/「surface always flat color」

- 页面由一幕**满出血深色 hero** 领起：暖调深色动态铺底（真站用循环视频，复刻的要点不是视频本身，而是**深色反转 hero 作明暗锚点**）+ 悬浮白色巨标 + 药丸 CTA。这是摆荡的**暗端**。
- 往下明暗摆荡**落在卡片尺度**：每一行三张卡里，总有**一张近黑（obsidian）或深紫（aubergine）暗卡**夹在浅色糖果卡之间——暗不是单独一整幕，而是**逐行插入的深色瓦片**，与浅卡共处一行。
- DESIGN.md 头部只标 `Theme: mixed` 却把界面写成「近白 canvas 偶尔渗入深紫」——真实的暗是**主动编排的节奏**（深 hero + 逐行暗卡），要主动补上：暗卡上文字用近白、暗卡同样吃圆角与饱和，不是灰暗的附属。

## 2. 糖果卡节奏 candy tiles ← 补 DESIGN.md「content card = 扁平纸白、无阴影」

- 真站功能卡**不是扁平纸白卡**：是一批 **24px 大圆角、满饱和填色的瓦片**，每张一色——淡紫（periwinkle）、矢车菊蓝（cornflower）、奶黄（buttercream）、腮红（blush）、灰（ash）、近黑（obsidian）、深紫（aubergine）。
- **关键复刻点**：DESIGN.md 把这套糖果色只当作「小按钮点缀」——真站把它**升格为整张大卡的底色**，多色卡并置打出「糖果店」节奏（airy ↔ intimate）。复刻若只给按钮上糖果色、卡片留纸白，就丢了 phantom 的整个身份。
- 卡底是**纯色填充**（非 CSS 渐变）；渐变般的观感来自卡内插画，不是底色。卡与卡之间靠近白 canvas 呼吸，不靠分隔线。

## 3. 插画 · 贴纸 · 产品截图 illustration ← 更正 DESIGN.md「no abstract graphics / no product screenshots」

- 卡里满是内容：**ghost 吉祥物**（俏皮破格）、**贴纸式图形**（如预测场景的 yes/no 彩色贴片、散落的几何色块）、**彩色有机色块（blob）插画**、以及**真实产品截图**（钱包余额 $200 / $18,207.41、approve-transaction 手机界面）。
- **更正**：DESIGN.md 说「无摄影 / 无产品截图 / 无抽象图形 / 纯排版」——与真站相反。phantom 是**插画与截图双重密集**的，排版只是承载它们的骨架。复刻要主动铺这层俏皮插画 + 截图，别做成纯字站。
- 这些是**内容资产**（每卡自备），本文件只记「用 / 怎么处理」：贴在饱和卡底上、圆角裁切、ghost 用 periwinkle、截图直接嵌卡不去彩。

## 4. 辉光 glow ← DESIGN.md faithful（重述为合成层设备）

- 主 CTA 是**浅上加浅**（淡紫按钮坐在近白面上），几乎与底同色——**只靠一道柔性淡紫辉光显形**（约 4px 弥散的淡紫外发光）。这是全系统**唯一**允许的「阴影」。
- 辉光也出现在大号淡紫 CTA 卡上（不只小按钮）。除这道淡紫晕外，系统**全扁平无投影**。

## 5. 字形设备 · ghost 内联 type device ← DESIGN.md faithful

- 招牌字形设备：**ghost 吉祥物替换 display 标题里的一处元音 / 内联嵌进标题**（渲染为 periwinkle），在克制排版里制造一处品牌俏皮与识别（「Trading tools for 〔ghost〕 everyone」这类）。
- **中文注意**：中文无元音可替——改用 ghost 作**标题内一处内联字形节拍**（嵌在词间）或一处 periwinkle 彩字替代那处品牌强调，**不硬塞**进方块字骨架里破坏字距。

## 6. 刻意拒绝 refuses（复刻时主动不做）← DESIGN.md Don'ts + 真站实测

> 站的身份也由它**拒绝什么**定义。这些是「刻意无」，复刻时必须**主动不做**。

- **药丸几何是招牌**：一切 nav 容器 / 按钮 / tag 用 100px 药丸，卡片 24px——**刻意无扁平锐角 nav 条**，万物皆软胶囊。
- **刻意无常规投影**：除主 CTA 那道淡紫辉光外，不加任何 drop-shadow；饱和卡靠色与圆角分离，不靠影抬起。
- **调色刻意窄**：糖果集只此几色（淡紫 / 矢车菊蓝 / 奶黄 / 腮红），Don't 引入集外饱和色；单一主紫（aubergine）扛全部结构活。
- **whisper-weight 不加粗**：通体 350，绝不用 600+ 求强调（350 是嗓音不是手段）。
