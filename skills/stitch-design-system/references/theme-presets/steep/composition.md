# Steep — 合成层（Composition Layer）

> DESIGN.md 的合成层补充。值层见 `adapter.css` / `rules.md`（同预置）；本文件记那些**单个 token 换不动、需多图层 / 滤镜 / 混合才成立**的长相——氛围铺底、明暗幕、辉光·毛玻璃、字形设备、刻意拒绝。**复刻 steep 缺了这层，只剩「平白纸 + 粗宋体」，丢掉全部高级感。** 合成层与 DESIGN.md 的平涂印象冲突时以本文件为准。

## 一句话 ← DESIGN.md 概览 + 真站观感

steep 是**分层合成的编辑排版**：每个大区块一张全出血 **位图 mesh 渐变铺底 + 细颗粒叠层**，浮动**产品截图拼贴**环绕衬线大标题；页面中途反复插入**近黑暗幕**作戏剧对比，暗底上的产品卡**发光**；标题**恒 400 衬线 + 一处斜体**做编辑强调。白纸是舞台，不是全部。

## 1. 背景氛围 backdrop ← 更正 DESIGN.md「no abstract graphics」

- 主区块各铺一张**全出血位图**：暖桃中心 → 冷（薰衣草 / 蓝）边的 **mesh 渐变位图**（是位图图像，不是 CSS 渐变——CSS 渐变只作它上面那层极淡的近白过渡）。铺底满宽、贴在内容之后。
- 铺底之上再叠一层 **SVG 细颗粒纹理**，以**叠加混合（overlay）**压上去——它消除 mesh 渐变的 banding、是「高级感」的直接来源，**别省**；省了铺底就发平、发脏。
- 另有一层极淡的 **近白线性渐变**（`in oklab`，近白 → 纯白）压在铺底顶，把位图往区块边缘柔化收干净。
- **更正**：DESIGN.md 说「无摄影 / 插画 / 抽象图形」——与真站相反，真实 steep **满屏氛围铺底**。DESIGN.md 里的 "warm highlight wash" 只指**桃色卡片**背景，**不是** hero 铺底，别混。

## 2. 明暗幕 dark act ← 补 DESIGN.md（其头部只标 light）

- 页面中途插入**近黑暗幕**作明暗戏剧对比：暗幕**满宽全出血**，产品截图在暗底上**发光**浮起；暗幕顶部叠一层淡白渐变、避免死黑压顶。
- 暗幕是**反复出现的编排节奏**，不是固定一处——落地区一道即够，功能 / AI 区可连着来好几道。
- 暗幕的黑**分档而非单一死黑**：从近黑（约 `#121212`）到略抬的炭黑（约 `#1a1a1a` / `#232323`）几档，相邻暗幕用不同深浅拉出层次，别所有暗幕都调成同一个黑。
- DESIGN.md 头部只写 `Theme: light`——那只说了浅色的一半。暗幕这半要主动补上：包含 on-dark 文本配色、暗底上产品卡的发光处理，与浅色区共存于同一页。

## 3. 辉光 · 毛玻璃 · 浮动拼贴 floating artifacts ← 补 DESIGN.md「Floating Artifact 只记 subtle shadow」

- 浮动 composer / 产品卡走**毛玻璃**：**背景模糊 12–16px** + **内阴影辉光**（顶部一道 inset 白微光，约 30% 强度），让卡片像浮在铺底之上的一层薄玻璃，而非硬贴。顶栏导航同样带背景模糊、半透明浮在铺底上。
- 产品截图**软投影 + 缩放错位**叠放：大扩散 `drop-shadow`（越靠前投影越深）+ **缩小到约半尺寸再错位重叠**（拼贴感由缩放 + 负位移造出，不是等比排版）。
- 局部产品图与底层以**正片叠底（multiply）**融合，让截图边缘吃进铺底、不留生硬白边。
- 白色浮动卡 20px 圆角 + 约 10% 软影是**唯一**赢得可见高度的元素（内容卡一律无影）。产品截图是**内容资产**——每页自备，不进主题值，本文件只记「怎么处理」（软影 + 毛玻璃 + 缩放错位 + 融合），不记具体图。

## 4. 字形设备 type device ← DESIGN.md Typography + 更正「斜体只在示例里顺带提」

- 标题 display / heading **恒 weight 400** 衬线，**永不加粗**——serif 低语权威而非加粗喧哗，加粗即破功。
- 每句里**一处** `<em>` 斜体做编辑强调（首页 "zero chaos"、AI 页 "your" 这类）。这是一处**确立的排版设备**，不是随处可用的装饰——一句一处、点到即止。
- **中文注意**：拉丁斜体无中文对应——中文标题改用**字号跳档 / 留白 / 一处彩字**替代那一处强调，**不硬套**机械斜切的伪斜体。

## 5. 刻意拒绝 refuses（复刻时主动不做）← DESIGN.md Don'ts + 真站实测

> 站的身份也由它**拒绝什么**定义。这些是「刻意无」，复刻时必须**主动不做**。

- 桃色 blush 一页**≤1 次**、只作编辑点缀，**绝不当背景**；须坐在白 / 雾灰面上。
- 内容卡（中性卡 / 桃色卡）**无阴影无边框**；只有浮动 artifact 才有软影 + 毛玻璃。
- **无彩虹色**——系统 97% achromatic，除桃 / 棕外禁蓝 / 绿 / 紫。
- 衬线**不加粗**（不 500 / 600）；斜体只**一句一处**。
- 产品截图**不灰化**——保留原彩、只加软影与投影（区别于会 grayscale 去彩的极简站）；截图承载的正是产品真实的界面色。
